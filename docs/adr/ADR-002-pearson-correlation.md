# ADR-002: 相関スコアに Pearson 相関係数を使う

- **日付**: 2026-06-22
- **状態**: Accepted

## 決定

異常シグナルと各メトリクスの Pearson 相関係数を相関スコアの主指標として使う。

## 理由

- 「エラー率が上がるとき DB レイテンシも上がる」という線形相関を定量化できる
- ClickHouse の `corr(x, y)` 集計関数で直接計算できるためコードが最小になる
- 解釈が直感的（-1〜+1）でデバッグしやすい

## トレードオフ

- 線形相関のみ検出可能（非線形・遅延相関は検出できない）
  → Phase 6 以降で DTW (Dynamic Time Warping) や CCF を検討
- 外れ値に敏感 → ログスケールの正規化を前処理に追加
